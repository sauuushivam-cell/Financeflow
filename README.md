

# FinanceFlow - Personal Expense Tracker

A Python-based Personal Expense Tracker built using Object-Oriented Programming (OOP) and File Handling.

## Features
- Add Income & Expenses
- Categorize Transactions
- Monthly Expense Report
- Automatic Balance Calculation
- JSON Data Storage
- Data Visualization using Matplotlib

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- File Handling
- JSON
- Matplotlib
